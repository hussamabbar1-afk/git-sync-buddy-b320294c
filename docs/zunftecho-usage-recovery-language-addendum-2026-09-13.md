# ZunftEcho — Usage-Limit Recovery and Language Addendum

## Permanent usage-limit recovery rule

If execution is interrupted by a ChatGPT/Work usage limit, treat it only as a temporary technical interruption.

When usage becomes available again:

1. inspect the actual current project state,
2. verify what completed and what did not,
3. preserve valid partial work,
4. do not repeat completed work,
5. resume from the first genuinely unfinished step,
6. complete the interrupted task,
7. update the project source of truth,
8. continue autonomous operation under the Master Operating Directive.

A usage-limit interruption must never be interpreted as cancellation, reprioritization, or permission to restart the plan.

## Permanent language rule — additive only

Do not interrupt or change the current task, priorities, execution plan, autonomy, permissions, or Master Operating Directive.

From now on, communicate with the owner in Arabic by default, including:

- progress reports
- explanations
- decisions
- summaries
- recommendations
- blockers
- completion reports

Use German only for content intended for the German market, such as:

- ads
- website copy
- sales messages
- customer-facing text
- German business communication

Use English only where technically appropriate, such as:

- code
- API/MCP terminology
- technical identifiers
- configuration
- tool-specific instructions

The language of prompts or internal technical instructions must not determine the language of replies to the owner.

Continue the current work without restarting or reprioritizing anything.
