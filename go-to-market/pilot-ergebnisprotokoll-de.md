# ZunftEcho – Pilot-Ergebnisprotokoll

Interne Arbeitsvorlage. Für jeden Betrieb separat führen und nur mit gekennzeichneten Test- oder
freigegebenen Kundendaten teilen.

## 1. Pilotrahmen

- Betrieb:
- Ansprechpartner:
- Pilotbeginn:
- Pilotende:
- eingesetzte Website/Domain:
- konfigurierte Leistungen und Gebiete:
- vereinbarte Kanäle:
- nicht enthaltene Funktionen:

## 2. Ausgangslage

- bisheriger Anfrageweg:
- typische fehlende Angaben:
- durchschnittliche Rückfragen pro Anfrage:
- Reaktion außerhalb der Bürozeiten:
- Übergabe dringender Fälle:
- verfügbare Ausgangsdaten und ihre Qualität:

## 3. Drei verbindliche Erfolgskriterien

Die Kriterien müssen vor dem produktiven Start messbar formuliert werden.

| Kriterium | Ausgangswert | Ziel | Messmethode |
|---|---:|---:|---|
| Vollständigkeit relevanter Pflichtangaben |  |  |  |
| Zeit bis zur menschlichen Übergabe |  |  |  |
| notwendige Rückfragen vor dem ersten Rückruf |  |  |  |

Optional: Anteil außerhalb der Bürozeit erfasster Anfragen, abgeschlossene Terminwünsche,
Abbruchquote oder Bewertung durch die zuständigen Mitarbeiter.

## 4. Funktionsabnahme vor dem Start

- [ ] Leistungen, Gebiete, Öffnungszeiten und Assistentenname bestätigt
- [ ] Sicherheitshinweise und menschliche Übergabe geprüft
- [ ] Benachrichtigung an den richtigen Empfänger geprüft
- [ ] Terminwunsch und Terminbestätigung eindeutig getrennt
- [ ] Widget auf Desktop und Mobilgerät geprüft
- [ ] Ansprechpartner und Reaktionsweg für Störungen festgelegt
- [ ] Daten- und Löschprozess besprochen

## 5. Ergebnis nach 30 Tagen

| Messpunkt | Ergebnis | Einordnung | Datengrundlage ausreichend? |
|---|---:|---|---|
| Pflichtangaben vollständig |  |  | ja / nein |
| menschliche Übergabe |  |  | ja / nein |
| Rückfragen vor Rückruf |  |  | ja / nein |

### Qualitative Beobachtungen

- Was hat dem Team Arbeit abgenommen?
- Wo waren Antworten oder Übergaben unklar?
- Welche Anfragen passten nicht zum vorgesehenen Ablauf?
- Welche Änderung wurde während des Piloten vorgenommen?
- Welche Funktion wurde bewusst nicht eingesetzt?

- [ ] Pilot endet ohne Fortsetzung
- [ ] monatliche Fortsetzung ausdrücklich beauftragt
- [ ] weitere Prüfung vereinbart; noch kein Monatsvertrag
